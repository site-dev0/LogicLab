# 🌐 LogicLab - Plataforma de Ensino
### O LogicLab é uma iniciativa de um jovem chamado Lucas Cabral que com sua vontade de ajudar o ensino de tecnologia, criou o LogicLab.
### Na plataforma o aluno pode EMITIR CERTIFICADOS SIMBÓLICOS GRATUITAMENTE além de ter seu próprio painel onde nele existem funções que ajudam o aluno. Tudo isso aprendendo com os módulos de exercícios onde o aluno treina sua lógica de programação e seus conhecimentos.

## Tecnologias usadas:
- HTML
- CSS
- JavaScript
- Git e Github

## Curiosidades:
